# Discussions of Place

A simple interactive photo album with keyboard navigation.

## Features
- ← / → arrow keys to cycle through images
- On-screen navigation buttons
- Touch swipe support on mobile
- Optional captions per image

## How to add photos
1. Drop your image files into the `images/` folder
2. Open `script.js` and add entries to the `images` array:

```js
{ src: "images/your-photo.jpg", caption: "A nice description" }
